# Jetpack Compose Skills

This skill is a collection of official Android Jetpack Compose skills. It acts as an umbrella for specific Compose-related capabilities.

For specific task instructions, please refer to the sub-skills included in this directory:
- [Adaptive UI](adaptive/SKILL.md): Instructions to make or update an app's UI so that it adapts to different Android devices including phones, tablets, foldables, laptops, desktop, TV, Auto and XR.
- [Migrate XML Views to Compose](migration/migrate-xml-views-to-jetpack-compose/SKILL.md): Instructions on how to migrate an Android app's UI from XML Views to Jetpack Compose.
- [Theming and Styles](theming/styles/SKILL.md): Instructions for theming and styles in Jetpack Compose.
