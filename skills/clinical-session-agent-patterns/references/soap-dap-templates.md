# Clinical Documentation & SOAP / DAP Note Templates

This reference provides standard structured templates for clinical, psychological, and therapy session notes.

---

## 1. SOAP Note Structure
- **Subjective (S)**: Client report, presenting feelings, symptoms, reported events. Direct quotes where appropriate.
- **Objective (O)**: Observable clinical data, affect, presentation, motor activity, speech rate/tone.
- **Assessment (A)**: Clinical interpretation, DSM-5 / ICD-10 diagnostic impressions, progress towards therapeutic goals.
- **Plan (P)**: Interventions delivered, homework assigned, risk assessment review, next session date.

---

## 2. Privacy & PII Scrubbing Rules
- Never export raw identifying client details (SSN, home addresses, phone numbers).
- Use pseudonymous identifiers (e.g. \`Client_A\`, \`Session_2026_09\`) in logs and external model prompts.
